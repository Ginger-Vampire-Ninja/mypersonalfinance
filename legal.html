Usage analytics

We use PostHog (EU Cloud) to collect anonymous usage analytics. This helps us understand how the Service is used so we can improve it. PostHog may collect:

  • Pages and features visited within the app
  • Actions taken (e.g. "added a transaction", "viewed cashflow")

  • Session and event timing data
  • JavaScript errors that occur in the app

This analytics data does not include any of your personal financial data. PostHog data is stored on PostHog's EU Cloud servers. You can read PostHog's privacy policy at posthog.com/privacy.
